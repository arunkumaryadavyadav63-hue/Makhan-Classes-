# Makhan Classes – Starter App

यह एक working responsive prototype है, जिसे मोबाइल Chrome में भी चलाया जा सकता है।

## इसमें अभी क्या है
- Class 1–8 selection
- Subjects
- Video Classes
- Notes/Test/Result/Notification/Teacher Support sections
- Demo Admin Panel
- YouTube video link publish
- Browser localStorage में demo data
